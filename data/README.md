# Source data

`claim_ledger.json` records where the manuscript explains each registered
numeric claim. `formalism_claim_ledger.json` declares the manuscript's
formalism-block labels and facet-lattice numbers so the render engine's
evidence registry resolves the `[@def:...]`/`[@prop:...]` cross-references.
Both are source metadata, not observation ledgers.

Keep paths relative to the project and validate the rendered package after
editing. See [AGENTS.md](AGENTS.md), [../docs/reproducibility.md](../docs/reproducibility.md),
and [../README.md](../README.md).
