# Skills

One directory per skill descriptor. This project ships a single skill:

- [`white-line/`](white-line/) — the operating walkthrough for the absence
  ledger: staged assessment, the worked example, the distributional views, the
  release sequence, and the failure gotchas.

A skill directory carries `SKILL.md` (the descriptor a runtime loads),
`AGENTS.md` (the folder contract), and `README.md` (this orientation).

Project root: [AGENTS.md](../../AGENTS.md) and [README.md](../../README.md).
